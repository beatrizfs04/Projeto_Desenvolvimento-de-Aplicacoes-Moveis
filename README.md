# Projeto de Desenvolvimento de Aplicações Móveis
## O que foi feito?
Neste projeto foi desenvolvida uma aplicação móvel para apoio à meditação, implementada no Android Studio com Flutter, chamada "Serene". 
A app foi pensada para ajudar os utilizadores em práticas de relaxamento através de diferentes funcionalidades complementares.

A aplicação inclui um sistema de login autenticado com o FireAuth da Firebase, garantindo a personalização da experiência e persistência 
dos dados do utilizador. E para o armazenamento usou-se o Firestore da mesma. Outra funcionalidade é um timer de respirações guiadas, que permite sessões cronometradas com 
indicações visuais e sonoras para práticas de respiração consciente.

Para além disso, foi criada uma página dedicada a músicas de meditação, com uma funcionalidade de pesquisa que permite encontrar 
faixas por título ou categoria. Os utilizadores podem guardar as suas músicas favoritas numa lista pessoal, acedendo 
rapidamente às suas seleções preferidas.

Este ajudou na consolidação de conhecimentos em desenvolvimento móvel com Flutter, integração com serviços cloud como 
o Firebase, e implementação de interfaces intuitivas para experiências de bem-estar digital.
